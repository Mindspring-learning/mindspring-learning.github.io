01 · Understand lists

What is a list?

A list is an ordered, mutable collection in Python. It can store multiple items, including values of different data types. Lists are written using square brackets, with items separated by commas.

subjects = ["Biology", "Computer Science", "English"]
print(subjects)
Output
['Biology', 'Computer Science', 'English']

Creating lists

numbers = [10, 20, 30, 40]
mixed = ["Mira", 16, 92.5, True]
empty = []
Remember: A list can be empty. Its elements keep their order, and the same value may appear more than once.

Indexing: access one element

Indexing starts at 0. Negative indices count from the end: -1 is the last element.

Element"Bio""CS""English""Maths"
Positive index0123
Negative index-4-3-2-1
subjects = ["Bio", "CS", "English", "Maths"]
print(subjects[0])
print(subjects[-1])
Output
Bio
Maths

Slicing: access a part of a list

The slice list[start:stop] includes the start index but excludes the stop index.

subjects = ["Bio", "CS", "English", "Maths"]
print(subjects[1:3])
print(subjects[:2])
print(subjects[2:])
Output
['CS', 'English']
['Bio', 'CS']
['English', 'Maths']
Common mistake: Accessing an index that does not exist raises IndexError. For example, a four-item list has indices 0 to 3, not 4.
02 · Work with lists

Changing and using list elements

Update an element

Lists are mutable, so an element can be replaced using its index.

marks = [78, 85, 91]
marks[1] = 88
print(marks)
Output
[78, 88, 91]

Functions and methods: what is the difference?

A function is called by writing its name and giving it data in parentheses, for example len(subjects). A method is an operation that belongs to an object; for a list, write the list name, a dot, and the method name, for example subjects.append("Art").

subjects = ["Bio", "CS"]
print(len(subjects))       # function
subjects.append("English") # list method
Output
2
Easy way to spot it: len(my_list) is a function called with a list. my_list.append("Bio") is a method called on that list.

Useful built-in functions

These functions work with lists and are written before the list in parentheses.

Useful list methods

List methods are called using dot notation: list_name.method(). Some change the existing list; others return information or a value.

MethodWhat it doesExample
append(x)Adds x as one item at the end.L.append(7)
extend(items)Adds each item from the given iterable.L.extend([7, 8])
insert(i, x)Inserts x at index i.L.insert(1, 7)
remove(x)Removes the first matching value x.L.remove(7)
pop(i)Removes and returns item at index i; without i, removes the last item.last = L.pop()
index(x)Returns the index of the first matching x.L.index(7)
count(x)Returns how many times x occurs.L.count(7)
sort()Sorts the existing list in place.L.sort()
reverse()Reverses the existing list in place.L.reverse()
copy()Returns a shallow copy of the list.new_L = L.copy()
clear()Removes all items from the list.L.clear()

Example: methods change the list

colours = ["purple", "blue"]
colours.append("pink")
colours.insert(1, "lavender")
print(colours)

colours.remove("blue")
removed = colours.pop()
print(colours)
print("Removed:", removed)
Output
['purple', 'lavender', 'blue', 'pink']
['purple', 'lavender']
Removed: pink

Example: methods that give a result

scores = [8, 5, 8, 2]
print(scores.count(8))
print(scores.index(5))
print(scores)
Output
2
1
[8, 5, 8, 2]
Important: sort() changes the original list and returns None. Use sorted(L) when you need a new sorted list and want to keep the original unchanged. Similarly, reverse() changes the list in place.

Traversing a list

A for loop can visit each element in order.

subjects = ["Bio", "CS", "English"]
for subject in subjects:
    print(subject)
Output
Bio
CS
English
03 · Revise and practise

Quick recap

  • Lists are ordered and mutable; they use square brackets.
  • Positive indexing starts at 0; negative indexing starts at -1 from the end.
  • Slicing uses an inclusive start and exclusive stop.
  • append() adds one item; extend() adds each item from an iterable.
  • remove() removes by value; pop() removes by index and returns the removed item.
