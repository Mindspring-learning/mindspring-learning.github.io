1Introduction to Python

A program is a set of instructions written to make a computer perform a task. A programming language provides rules and symbols for writing those instructions.

Python is a high-level, general-purpose programming language. Its syntax is designed to be readable, which makes it useful for beginners as well as professional developers.

Important features of Python

Readable syntax

Programs can often be understood without many complicated symbols.

High-level language

It hides many low-level hardware details from the programmer.

Interpreted execution

Python uses an interpreter to run code; implementation details may vary.

Portable

Programs can often be used on different operating systems with little change.

Free and open-source

Python is available under an open-source licence.

Rich libraries

Many built-in modules and external packages extend its capabilities.

Where is Python used?

  • Web and software development
  • Data analysis and visualisation
  • Artificial intelligence and machine learning
  • Automation and scripting
  • Scientific and educational applications
Remember: Python is case-sensitive. For example, marks, Marks and MARKS are different names.

2Working with Python

Interactive mode

In interactive mode, you type a command at the Python prompt and the interpreter responds immediately. The prompt is commonly shown as >>>.

>>> 8 + 4
12
>>> print("Hello, Python!")
Hello, Python!

Best for: trying small expressions, checking results and learning syntax.

Script mode

In script mode, you write a sequence of statements in a file, usually ending in .py, and run the file.

# hello.py
print("Hello, Python!")
print(8 + 4)
Output
Hello, Python!
12

Best for: writing, saving, editing and running complete programs.

Interactive modeScript mode
Commands are entered one at a time.Statements are saved in a source file.
Results appear immediately for expressions.Results appear when the script is executed.
Useful for quick experiments.Useful for longer, reusable programs.

3Tokens in Python

Tokens are the smallest meaningful units of a program recognised by Python. Common introductory categories include keywords, identifiers, literals and operators; punctuation symbols such as commas and colons also help form statements.

total = price + 5

In this statement, total and price are identifiers, = and + are operators, and 5 is an integer literal.

Tip: When asked to identify tokens, break the statement into its meaningful names, values, operators and punctuation.

4Keywords

Keywords are reserved words with predefined meanings in Python. They cannot be used as ordinary variable names.

Examples: if, else, elif, for, while, break, continue, def, return, class, import, in, is, and, or, not, pass, True, False and None.

if age >= 18:
    print("Adult")

Here, if is a keyword. The colon introduces the indented block that belongs to the condition.

Common mistake: if is a keyword, but If is not the same keyword because Python is case-sensitive.

5Identifiers and naming rules

An identifier is a name given to a program element, such as a variable, function or class.

Rules for identifiers

  1. Use letters, digits and underscores.
  2. The first character cannot be a digit.
  3. Spaces are not allowed.
  4. A Python keyword cannot be used as an identifier.
  5. Identifiers are case-sensitive.
  6. Characters such as @, # and % are not allowed in ordinary identifiers.

7Variables and assignment

A variable is a name that refers to an object or value. In Python, a variable name is created when it is assigned a value.

age = 16
student_name = "Mira"
height = 1.62

The symbol = is the assignment operator. It assigns the object on the right to the name on the left; it does not mean “is equal to” as in mathematics.

Reassigning a variable

value = 10
print(value)
value = "Python"
print(value)
Output
10
Python

Python is dynamically typed, so a name can be assigned objects of different types at different times.

Multiple assignment

a, b = 10, 20
print(a, b)

x = y = 0
print(x, y)
Output
10 20
0 0

Comments

Comments explain code to people reading it. A single-line comment begins with #.

# Calculate the total
first = 10
second = 20
print(first + second)

Python ignores the comment during normal execution.

Mutable and immutable objects

Mutable objects can be changed after creation; lists and dictionaries are common examples. Immutable objects cannot be changed in place; integers, floats, strings and tuples are examples.

items = [10, 20, 30]
items[0] = 99
print(items)
Output
[99, 20, 30]
Note: A string is immutable, but a variable can be reassigned to a different string.

10Expressions and precedence

An expression combines values, variables, operators and sometimes function calls to produce a result.

result = 5 + 3 * 2
print(result)
Output
11

Multiplication takes place before addition. Parentheses can make the intended order clearer.

print((5 + 3) * 2)
print(2 ** 3 ** 2)
Output
16
512

Exponentiation is evaluated from right to left, so 2 ** 3 ** 2 means 2 ** (3 ** 2).

Useful precedence order

From higher to lower precedence, a simplified guide is:

  1. Parentheses and grouping
  2. Exponentiation (**)
  3. Unary operators (+x, -x, not has its own lower precedence)
  4. Multiplication, division, floor division and remainder
  5. Addition and subtraction
  6. Comparisons, membership and identity tests
  7. not, then and, then or
Exam tip: When solving an expression, write down each step. Do not evaluate strictly from left to right unless the operators have the same precedence and associativity allows it.

11Input and output

The print() function

print() displays values or text on the screen.

name = "Asha"
marks = 92
print("Name:", name)
print("Marks:", marks)
Output
Name: Asha
Marks: 92

By default, print() separates multiple arguments with a space and ends with a newline. The sep and end arguments can change this behaviour.

print("2026", "10", "18", sep="-")
print("Hello", end=" ")
print("there!")
Output
2026-10-18
Hello there!

The input() function

input() reads a line entered by the user and returns it as a string.

name = input("Enter your name: ")
print("Welcome", name)
Example interaction
Enter your name: Asha
Welcome Asha
Important: Even if a user types digits such as 25, input() returns the text "25". Convert it when you need a number.

12Type conversion

Type conversion means changing a value from one data type to another.

Explicit conversion (type casting)

The programmer requests conversion using functions such as int(), float(), str() and bool().

a = int("25")
b = float("4.5")
c = str(100)

print(a + 5)
print(b + 0.5)
print(c + " students")
Output
30
5.0
100 students

Using input to calculate a total

first = int(input("Enter first number: "))
second = int(input("Enter second number: "))
total = first + second
print("Total =", total)
Example interaction
Enter first number: 12
Enter second number: 8
Total = 20

Implicit conversion

In some operations, Python automatically converts compatible numeric values to a suitable common type.

answer = 5 + 2.5
print(answer)
print(type(answer))
Output
7.5
<class 'float'>
Watch out: int("hello") raises a ValueError. Conversion is only possible when the input has a suitable format.

13Errors and debugging

A program may fail because its syntax is invalid, an operation is not possible, or its logic does not produce the intended result.

Error typeWhat it meansExample
Syntax errorThe code breaks Python's grammar rules.if x > 3 print(x) — missing colon
Runtime error / exceptionAn error occurs while the program runs.10 / 0 — ZeroDivisionError
Logical errorThe program runs but gives the wrong result.Using + when calculating a difference

Debugging checklist

  • Read the error message carefully.
  • Check spelling, capitalisation, quotes, brackets and colons.
  • Check indentation and the order of statements.
  • Test calculations with small values.
  • Print intermediate results to locate a logic error.

★Quick recap

  • Python is a readable, high-level, general-purpose programming language.
  • Interactive mode is useful for quick experiments; script mode stores code in a file.
  • Tokens are the meaningful units that make up a program.
  • Keywords are reserved; identifiers are names chosen by the programmer.
  • Literals are values written directly in code.
  • Variables refer to objects and are created through assignment.
  • type() reports an object's type.
  • = assigns; == compares values.
  • / performs division, // floor division, and % gives the remainder.
  • input() returns a string; convert it for numeric calculations.
  • Syntax errors, runtime exceptions and logical errors are different kinds of problems.
